# Library Inventory Manager

A simple Python command-line application to manage a library’s book inventory. It uses OOP principles and JSON file persistence.

---

## Features

- Add books (title, author, ISBN)
- Issue and return books with status tracking
- View all books in inventory
- Data saved/loaded in `books.json` automatically

---

## Setup & Run

1. Ensure Python 3 is installed.
2. Clone/download project files (`book.py`, `inventory.py`, `main.py`).
3. Run: python main.py
